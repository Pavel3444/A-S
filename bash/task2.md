## Task 2.4

**Задание:**
Вывести последние 50 строк файла /var/log/auth.log.
Организовать просмотр новых записей в реальном времени.
Вторым способом вывести первые 20 строк журнала.

**Решение:**

В Kali Linux отсутствует /var/log/auth.log, поэтому используется journalctl.

```bash
sudo journalctl -n 50
sudo journalctl -f
sudo journalctl --no-pager | head -n 20
```

Вывести 10 IP-адресов с наибольшим количеством неудачных попыток.

**Решение:**

Используется тестовый файл /tmp/auth_test.log вместо отсутствующего auth.log.

```bash

```

## Task 2.15

**Задание:**
Провести расследование подозрительного процесса, который может быть майнером.
Найти процессы с наибольшим потреблением CPU.
Определить пользователя и путь к исполняемому файлу подозрительного процесса.
Проверить, какие порты прослушивает процесс.
Запустить сетевой слушатель на порту 4444 для проверки подключения.

**Решение:**
```bash
ps aux --sort=-%cpu | head -n 10
sudo readlink -f /proc/606/exe
sudo ss -lntp | grep 'pid=606,'
nc -lvp 4444
```
